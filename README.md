# 本地足迹地图演示（脱敏示例）

这是一个**仅供本地运行、已脱敏**的 React + Vite 演示仓库。它包含网页看板、移动端采集入口、统计卡片、地点标签与路线回放；所有业务数据、身份信息、平台配置、服务端连接及内部链接均已移除或替换为示例内容。

## 安全与来源说明（请先阅读）

- 本目录是**脱敏示例**，从源工作区仅复制了当前的非 `.git` 文件，不包含原项目的任何 Git 历史、reflog、提交对象或远端配置。
- 当前仓库是全新 `git init` 的**本地仓库**：未设置任何 remote，且未执行任何 commit。是否提交由使用者自行检查后决定。
- **禁止**在此仓库或任何派生产物中放入：真实凭据、密钥、内部域名、内部 Git 地址、真实业务数据、真实人员或商户信息。
- 示例数据（`示例城市甲/乙/…`、`示例区域一/二/…`）均为占位文本，不代表任何真实地点或业务。

## 本地运行

要求：Node.js 18 或更高版本（已在 Node 23 下验证）。

```bash
# 1. 安装依赖
npm install

# 2. 本地开发预览（默认 http://127.0.0.1:5173 ）
npm run dev

# 3. 生产构建（产物输出到 dist/ ）
npm run build

# 4. 本地预览构建产物
npm run preview
```

## 安装为手机 App

应用内顶部有“安装 App”按钮，会按设备展示相应指引。

- iPhone / iPad：使用 Safari 打开 HTTPS 地址，点击“安装 App”，再按引导从“分享”菜单选择“添加到主屏幕”。
- Android：使用 Chrome 打开 HTTPS 地址，点击“安装 App”；若浏览器支持，会弹出系统安装确认。
- 安装后会以独立窗口打开；地图、已访问页面和应用外壳可离线使用。票据 OCR 首次使用需下载本地语言模型，截图不会上传。

## 推荐的修改入口（面向 GPT / 二次开发）

- 主页面与示例数据：`src/pages/TripMapDashboard.jsx`
  - 包含 `#dashboard` 网页看板和 `#collect` 移动采集入口。
- 本地数据与示例记录：`src/lib/tripStore.js`
  - 记录保存在浏览器本地；同一浏览器内采集后看板立即更新。
  - 跨设备请从“数据同步”导出 JSON，再在另一台设备导入。该机制不是云同步，也不会上传数据。
- 全局样式：`src/index.css`
- 页面挂载入口：`src/main.jsx`（一般无需改动）

> 仓库已移除未被入口 `src/main.jsx` 使用的死代码（`src/App.jsx`、`src/nav-items.jsx`、`src/pages/Index.jsx`），它们引用了 `package.json` 中不存在的依赖，删除不影响构建。请勿重新引入这些文件或对应的内部路由/组件依赖。

## 已知限制

- 全国地图数据已随应用打包，并会由 PWA 缓存；首次安装后可离线查看地图和采集记录。
- 图表模块仅在打开“网页看板”时加载，手机采集页不会下载地图与图表代码。
- 本项目不含账户、云端数据、后台接口或真实跨设备自动同步。若要实现登录后实时同步，应新增经过安全审查的后端、身份认证与数据最小化策略，不能直接把本地存储替换成未鉴权接口。
- 票据 OCR 在当前设备浏览器中运行，不会上传截图；首次使用会下载中文/英文离线识别模型，并由浏览器缓存。识别结果必须由用户核对后才会保存为足迹。
- `.gitignore` 已显式忽略 `.npmrc`、`.yarnrc`、`.catpaw/`、环境文件、凭据、依赖与构建产物；请勿绕过该忽略规则提交敏感文件。
